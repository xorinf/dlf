About this demo

Single-file HTML that talks to the ISL-Bridge FastAPI backend.

Live path: the webcam section captures ~10 frames/sec into a 16-frame rolling window (~1.6s), batches them as JPEGs, and POSTs to /predict_frames every 2.5s. MediaPipe Pose + HandLandmarker draw a person / hand box on the preview in real time and the current top-1 + confidence label rides on top of it. A confident new sign (above the threshold, past the cooldown) is appended to the Translation panel below and optionally spoken.

File / sample path: upload a .mov / .mp4 / .webm or click "Use a sample clip" to run /predict or /sample_predict on a one-shot clip.

Honest note: the on-disk working subset covers 2 INCLUDE classes (fall, summer). Numbers reported in the README are pipeline-completeness only.
