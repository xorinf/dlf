About this demo

This is a single-file HTML page that talks to the ISL-Bridge FastAPI backend.

It accepts a .mov or .mp4 from your disk (or a sample clip bundled with the project), POSTs it to /predict, and shows the model's top guesses with confidence. The "Speak prediction" button uses the browser's built-in speech synthesis — no server round-trip.

Honest note: the on-disk working subset covers 2 INCLUDE classes (Fall, Summer). Numbers reported in the README are pipeline-completeness only.
